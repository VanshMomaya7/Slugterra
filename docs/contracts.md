# Shared runtime contracts

Ratified for M0 on 2026-09-06 by Codex from Claude's `docs/m0_interface_proposal.md`. Godot 4.7.2-stable is the local pin; the project must remain loadable with no licensed assets.

## Ownership

Content definitions live in `data/`; runtime code lives in `src/`; scenes assemble them. Codex owns autoloads, slug/combat runtime, project settings and repository tooling. Claude owns player presentation, UI, scene assembly and NPC/world content. Shared files are changed by one owner per task and reviewed by the other.

## Authoring rules

- Commit `.gd.uid` sidecars generated by Godot; never bulk-regenerate or delete them.
- Use Godot 4 APIs: `CharacterBody3D.velocity` plus `move_and_slide()`, `PackedScene.instantiate()`, `create_tween()`, `PhysicsRayQueryParameters3D.create()`, `StringName` content IDs, metres/seconds/m/s.
- Persist stable IDs and plain data, never live nodes or scene references. Transient typed events may carry live nodes.
- Do not save Project Settings from the editor in another owner's task; hand-edit `project.godot`.

## M0 constants

Charge lasts 0.6 scaled seconds and maps monotonically from 20 to 62 m/s through one `ChargeConfig`. A shot transforms when its launch speed is at least the equipped breed threshold (44.7 m/s for Infurnus). Impact during the 0.25-second visual transform resolves once as transformed damage. A dud does no damage, XP, energy or cooldown cost; it waits 1.5 seconds, then returns. Successful transformed shots return in about 1.2 seconds and begin the breed cooldown. A shot is manually integrated and swept between positions.

`TimeController` owns the minimum of keyed time-scale requests. Gameplay timers use scaled physics delta. Hitstop and UI animation timers use unscaled time.

## Launch boundary

Claude's `Blaster.release()` builds a `LaunchRequest` and calls `SlugLauncher.launch()`. The launcher reserves exactly one `SlugInstance`, creates a `SlugProjectile` under the `projectile_container` node, and returns `LaunchResult`. The projectile owns the reservation until return or teardown. Availability transitions are `READY`, `IN_FLIGHT`, `DUD_WAIT`, `RETURNING`, `COOLDOWN`, `GHOULED`.

## EventBus

World observers subscribe to `slug_launched`, `slug_transformed`, `slug_dud`, `slug_hit`, `slug_returned`, `slug_availability_changed`, `slug_experience_gained`, `damage_dealt`, status, and death signals. Save data uses IDs rather than event object references.

## Physics layers

1 world, 2 player, 3 NPC/dummy, 4 reserved projectile, 5 hurtbox, 6 interactable, 7 trigger, 8 mecha, 9 camera occluder, 10 wild slug. Projectile sweeps use world/NPC/hurtbox masks and exclude the shooter.
